# 「较真」产品说明计划书（骨架 v0）

> 初审重点考核项（场景价值 40%）。本骨架赛前填好非 demo 部分，48h 内补 demo 截图。
> 结构照评审维度排，让评委按维度打分时一一对得上。

## 一、问题与场景价值 ⟵ 打「AI 场景价值 40%」
- **真痛点**：会看不会说。学生/职场新人读了一堆知乎高赞，自己一开口论证就散——主张不清、证据是断言、逻辑有洞、从不回应最强反方。备考问答、面试答辩、写作、当知乎答主，全卡在"论证力"。
- **为什么现在**：AI 满地"帮你总结/帮你写"，把人的思辨能力**外包**掉了。市场缺的是**训练你自己论证**、而不是替你论证的工具。
- **知乎生态内价值**：知乎是中文最大的**观点/论辩**平台，"认真你就赢了"是它的魂。提升用户的论证质量 = 直接提升社区讨论质量（知乎核心 KPI）。这不是外挂功能，是长在知乎基因上的。

## 二、产品方案（核心闭环）
1. 选一个有争议的议题（安全域模板：学习/职业/科普/生活/产品选型）
2. 知乎搜索拉正反方**高权威高赞**回答 + 精选评论（含反驳）→ 构成"论证场"
3. 用户写下自己的论证
4. **判分引擎**按 4 维 rubric 评分（主张/证据/逻辑/反方处理）+ 逐字标出逻辑谬误 + 指出你漏掉的最强反方
5. 对照：知乎高赞是怎么论证的、最强反方长什么样 → 你改一版，看分数变化

## 三、技术实现 ⟵ 打「创新度 25% + 反套壳」
- **判分引擎**（护城河，见 rubric.md）：reasoning judge + 4 维锚定 rubric + 谬误闭集 + 强制引用原文 span + 结构化输出。
- **知乎 API 用法**：知乎搜索（内容源，5000/天）＋ **AuthorityLevel 权威分级**（当准 ground-truth）＋ **精选评论**（当现成反方）＋ RankingScore 排序。直答 API 做"知乎官方视角对照答案"（可选）。本地缓存去重，遵守 API 规范。
- **为什么判分可信（4 条）**：锚点明确消除分歧主因 / 每个判定引用原文可核 / 谬误闭集不瞎发明 / 对照知乎权威内容有外部锚。
- **不是套壳**：护城河是"判得准且可核"的**判分工程**，不是"调 LLM 出题"。（正面回击评委对 generic LLM wrapper 的疲劳）

## 四、与知乎生态契合度 ⟵ 打「场景价值」的生态维度
- 数据用法：只用官方开放平台接口，权威分级/精选评论都是知乎独有信号；严禁批量爬取、滥用用户数据（合规）。
- 落地想象：可作为知乎"回答质量辅助"、答主训练营、盐选知识付费的配套练习工具。

## 五、创新点 & 差异化
- 满地 AI 在**判记忆/替你写**；「较真」判**你的论证质量**并训练它——市面稀缺。
- 把"LLM-as-judge 可信度工程"（学界 2026 硬核方向）落成一个普通人能用的思辨教练。
