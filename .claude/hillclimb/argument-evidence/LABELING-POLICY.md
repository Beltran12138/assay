# argument_evidence 标注口径（待签字）

锚点原文：`fixtures/argument/RUBRIC.md` 维度 2。

| 分 | 锚点原文 | 本次执行口径（补充） |
|---|---|---|
| 0 | 纯断言，无任何证据 | 只有结论、口号、类比或「常识」「公认」，没有任何事实、数据、案例或机制 |
| 1 | 有证据但与主张弱相关 / 来源不可核 | 证据只有个人经历、「我身边」、无出处统计（如「我们校招 65% 是硕士」）；或机制只是一句笼统断言；或机制写错了 |
| 2 | 相关且可核的证据支撑主张 | 至少有一条读者能公开核实的证据（具名来源、公开事实、公认机制或可核数据），并且确实在支撑主张 |
| 3 | 多类证据（数据 / 案例 / 机制）+ 说明证据如何支撑主张 | 满足 2，另外至少两类证据，并且写明了证据和结论之间的推导 |

四条执行规则（锚点原文没写，是我补的，请重点看）：

1. **先找主张再评证据**。截段文字以这一段里最主要的主张为准；如果有好几个主张，就评中心主张，子论点上的证据只算辅助。
2. **「可核」= 读者能公开核实**，不要求一定附链接。具名研究、书名、公开统计、公认的生理或技术机制都算可核；个人经历和自报的内部数据不算。
3. **能核但明显错的证据，按 1 处理**（例：cardio-12 把「热量缺口」说成「糖原缺口」）。
4. **只看证据，不看主张对不对，也不看文风**。主张站不住但证据扎实，照样可以给高分。
